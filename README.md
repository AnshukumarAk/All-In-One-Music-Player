# All-In-One Music Player

An Android music player that plays the audio already on your phone —
browse by album, see album art, and play without an account or a network.

## Built with

- Java · Android SDK
- MediaPlayer for playback
- RecyclerView for the library and album lists

## Getting started

```bash
git clone https://github.com/AnshukumarAk/All-In-One-Music-Player.git
```

Open the project in Android Studio, let Gradle sync, and run it on a device
or emulator. Reading local audio needs the storage/media permission, which
the app asks for on first launch.
